VERIFICAÇÃO DE INSCRIÇÃO

Dev Auxiliar

O Dev Auxiliar confirma se a sua conta Google está inscrita no canal do YouTube @JTLTDA_DEV e libera o acesso exclusivo no servidor Discord JTLTDA DEV.

Como funciona

  1. Dentro do Discord, clique em Ativar minha inscrição no canal de verificação.
  2. Entre com a conta Google que está inscrita no canal.
  3. Nosso serviço consulta a YouTube Data API e confirma a inscrição.
  4. Se confirmada, você recebe automaticamente o cargo 🌟 Inscrito no Discord.
Inscrever-se no @JTLTDA_DEV

Este app usa exclusivamente o escopo de leitura youtube.readonly apenas para verificar a sua inscrição. Nenhum dado pessoal é armazenado.
